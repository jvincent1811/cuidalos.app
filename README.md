# Cuidalos.app — GitHub Pages

Sitio estático de **cuidalos.app** (Cuidalos Escuela + Cuidalos Abuelitos).

## Publicar

1. Sube **todo el contenido** de esta carpeta a la raíz del repositorio (incluye `CNAME` y `.nojekyll`).
2. En Settings → Pages, elige la rama y carpeta raíz.
3. El dominio `cuidalos.app` queda configurado vía el archivo `CNAME`.

## Páginas

- `index.html` — Cuidalos Escuela (página principal)
- `abuelitos.html` — Cuidalos Abuelitos (cuidalos.app/abuelitos.html)
