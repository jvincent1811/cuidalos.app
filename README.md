# cuidalos.app

Sitio compilado listo para GitHub Pages.

1. Sube el contenido de esta carpeta a la raíz de tu repositorio (o a la rama `gh-pages`).
2. El archivo `CNAME` ya incluye el dominio `cuidalos.app`.
3. En Settings > Pages, selecciona la rama y carpeta raíz. GitHub detectará el CNAME automáticamente.
