# Cuidalos.app — sitio público

Contenido estático listo para GitHub Pages.

1. Sube **todo** el contenido de esta carpeta a la raíz de tu repositorio (incluye `CNAME` y `.nojekyll`).
2. En Settings → Pages, selecciona la rama y la carpeta raíz.
3. El archivo `CNAME` apunta a `cuidalos.app`; conserva el dominio personalizado en Settings → Pages → Custom domain.
