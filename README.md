# Cuidalos.app — GitHub Pages

Sitio estático de **cuidalos.app** (Cuidalos Escuela + Cuidalos Abuelitos).
Todo el diseño y el código viajan DENTRO de cada HTML: ya no hay carpeta `assets` que pueda quedar desactualizada.

## Publicar (importante)

1. **BORRA primero todo lo que hoy tienes en el repositorio** (incluida la carpeta `assets` vieja) para que no queden archivos de versiones anteriores.
2. Sube **todo el contenido** de esta carpeta a la raíz del repositorio:
   - `index.html` y `abuelitos.html`
   - la carpeta `images/`
   - `favicon.svg`, `CNAME` y `.nojekyll`
3. En Settings → Pages verifica que el dominio sea `cuidalos.app` (el archivo `CNAME` ya lo trae configurado).
